## 📖 About This Repository

This repository contains my **Dart learning journey**, organized from fundamental programming concepts to advanced Object-Oriented Programming and Exception Handling.

The goal is not simply to write code, but to **understand how Dart works, practice each concept, solve problems, and build a strong foundation for Flutter development.**

---

## 🎯 Learning Goals

- Understand Dart fundamentals
- Build strong programming fundamentals
- Master Object-Oriented Programming
- Understand Exception Handling
- Practice writing clean and readable Dart code
- Solve practical coding exercises
- Build a strong foundation for Flutter development
